# Summary of changes for run 32881386-8e73-489b-973d-eae2b0a08795
I fixed the remaining problems with the Granule port. **All 209 golden tests now pass** when you run `lake test`, up from 205 of 207.

**What changed**
- **Equation name check:** If an equation's name doesn't match its signature (`foo : Int` followed by `f00 = 5`), the parser now stops with Granule's own message: ``Name for equation `f00` does not match the signature head `foo` ``. A group of equations with mixed names gets Granule's "Identifier … in group of equations does not match …" message. The parser in `RequestProject/Granule/Parser.lean` can now report a fatal error with a message instead of only a token position.
- **Error output:** Errors are now formatted the way Granule formats them: the same headings (for example "Parse error" and "Error during evaluation") and no extra trailing newline. A missing import now reports `StdLib/bogus.gr: openFile: does not exist (No such file or directory)`.
- **Negative tests:** The test runner now also runs the two negative tests whose expected output is a parse error (`signature-equation-name-mismatch.gr` and `bogus-import.gr`). Both match their `.output` files exactly. The other negative tests need Granule's type checker, which isn't ported, so they still don't run.
- **`Files.gr` / `FilesBoxed.gr`:** As you chose, these now read a stand-in file at `RequestProject/Granule/fixtures/LICENSE`. That file says it is only a test fixture and not a licence. The runner uses it only when there is no `LICENSE` in the working directory, so a real one takes priority. It is only used for files opened read-only by relative path.
- **`lake test` was broken:** It failed with "invalid test driver: unknown … 'granule-test'". The earlier summary said this worked, but it didn't. To fix it I renamed the test executable's Lake target to `granuleTest`; the built program is still `granule-test`.

`README.md` and the docs in `Test.lean` are updated. The library and both executables build, there is no `sorry` in the project, and everything is committed and pushed.
